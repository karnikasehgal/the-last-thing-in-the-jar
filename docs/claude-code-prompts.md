# What to type in Claude Code

Open Claude Code in the elpis folder. All the rules and plans are in files it reads by itself, so you can keep it short.

**To keep building:**
```
next
```

**When something bothers you** (say it however you want):
```
feedback: ______
```

**When you're done for the day:**
```
wrap up
```

That's it. Claude in Chat (Cowork) and Claude Code share this folder: Claude Code writes `docs/STATUS.md` after every step, and Chat reads it. To get Chat's opinion, just tell Chat "check the game".
